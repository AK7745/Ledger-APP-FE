# ledger-web

Frontend for **Ledger** — a minimal, clean invoicing & payment-tracking app.

## Stack

- **Next.js** (React) — consumes the `ledger-api` backend.

## What it shows

- Parties (customers / suppliers) with running balances.
- Create & send invoices; record bills.
- Record payments and allocate them to invoices/bills.
- **Per-client statement** — every invoice and payment in one timeline with a running balance. The screen that ends "did I pay you?" disputes.
